# Desarrollo del prototipo de página web para Naure Solutions (Consultoría especializada en metodologías ágiles)

El proyecto está compuesto por la parte backend con API REST y un frontend interactivo con parte cliente y administrador. El desarrollo de la web al completo se llevará a cabo en el siguiente repositorio: <a href="https://github.com/mariamira6/Naure-Solutions" target="_blank">Naure Solutions</a>

**Funcionalidades completadas:**
- **Rol administrador**: Gestión de servicios (Visualizar servicios y Añadir nuevos servicios), Análisis de datos (gráficos y mapas de ventas).
- **Rol cliente**: Pestaña de Servicios contratados
  - Visualización de contrataciones
  - Visualización de citas generales por servicio en calendario
  - Detalle de servicio
  - Visualización de citas específicas vinculadas a un servicio concreto
  - Visualización de tramos de pago vinculados a un servicio concreto
- **Rol anónimo**: Página principal, Menú de servicios, Detalle de Servicios, Inicio de sesión.

## Tecnologías y herramientas principales
- **Backend:** .NET Core 8, C#, Entity Framework  
- **Base de datos:** SQL Server  
- **Frontend:** Vue.js, Bootstrap, HTML5  
- **Pruebas endpoints:** Postman, Swagger  
- **Control de versiones y arquitectura:** Git, SOA  
- **API RESTful**
- **Unit Testing**

## Puntos clave del proyecto
Análisis y desarrollo de una aplicación web con servicios REST, incluyendo backend, frontend y base de datos.  
- **Roles:**  
  - **Cliente:** Vista y gestión de contrataciones.  
  - **Administrador:** Panel de administración (CRUD, análisis de ventas).  
  - **Anónimo:** Vista general de servicios.  
- **Componentes**: mapas, gráficos y calendarios, entre otros.  
- Diseño y desarrollo de **tests unitarios** para asegurar la calidad del código.
